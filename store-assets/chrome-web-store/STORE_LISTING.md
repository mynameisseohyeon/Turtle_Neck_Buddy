# Chrome Web Store Listing

## Item Basics

- Name: Turtle Neck Buddy
- Category: Productivity
- Language for first listing: Korean
- Suggested secondary listing: English
- Single purpose: Help long-session computer users build neck and shoulder stretching habits through quiet browser reminders.

## Short Description

거북목 예방을 위해 정해진 시간마다 조용히 알려주는 30초 목/어깨 스트레칭 확장 프로그램

## Detailed Description

Turtle Neck Buddy는 오래 앉아 컴퓨터를 사용하는 사람을 위한 목/어깨 스트레칭 알림 확장 프로그램입니다.

집중을 방해하지 않도록 평소에는 화면에 나타나지 않고, 사용자가 정한 시간이 되었을 때만 화면 가장자리에서 거북이가 살짝 기웃거리며 스트레칭 시간을 알려줍니다. 알림을 받으면 바로 30초 스트레칭 루틴을 시작하거나, 바쁜 순간에는 5분 뒤로 미룰 수 있습니다.

주요 기능:

- 설정한 시간마다 나타나는 조용한 스트레칭 알림
- 화면 가장자리에서 기웃거리는 거북이 오버레이
- 턱 당기기, 목 기울이기, 어깨 돌리기 중심의 30초 스트레칭 루틴
- 바쁠 때 사용할 수 있는 5분 뒤 알림
- 오늘 완료 횟수와 주간 기록 확인
- 알림 간격, 언어, 거북이 크기, 조용한 모드 설정

Turtle Neck Buddy는 귀여운 캐릭터보다 습관 형성에 집중합니다. 사용자가 일을 멈추지 않아도 될 만큼 조용하지만, 목을 쉬어야 할 때는 충분히 알아차릴 수 있도록 도와줍니다.

## English Listing Draft

### Short Description

A quiet 30-second turtle stretch reminder for your neck and shoulders.

### Detailed Description

Turtle Neck Buddy helps people who spend long hours at a computer build a gentle neck and shoulder stretching habit.

The turtle stays out of sight while you focus. When your chosen reminder time arrives, it quietly peeks from the edge of the browser and invites you to stretch. You can start a guided 30-second routine right away or snooze the reminder for 5 minutes.

Key features:

- Quiet stretch reminders based on your chosen interval
- A turtle overlay that peeks from the edge of the page
- A 30-second routine for chin tucks, neck tilts, and shoulder rolls
- 5-minute snooze for busy moments
- Daily completion count and weekly habit record
- Settings for interval, language, turtle size, and quiet mode

Turtle Neck Buddy is designed to be calm, friendly, and low-interruption. It helps you notice your posture without turning your browser into another distraction.

## Demo Video Script

Target length: 30 to 45 seconds.

1. Install or load the extension.
2. Open a normal web page.
3. Show the first-run turtle guide asking the user to click the Chrome extension icon.
4. Click the Turtle Neck Buddy extension icon.
5. Choose a stretch reminder interval.
6. Confirm that the turtle disappears while the timer is not due.
7. Fast-forward or set a short test interval.
8. Show the turtle peeking from the page edge with the existing stretch reminder bubble.
9. Click Start and show the 30-second routine.
10. Complete the routine and show today's completion count increasing.
