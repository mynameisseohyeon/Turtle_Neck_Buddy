# Turtle Neck Buddy

Turtle Neck Buddy is a Chrome Extension MV3 popup that reminds people to take a short neck and shoulder stretch break. The MVP is local-first: no login, no backend, no camera, and no external API.

## Stack

- Chrome Extension Manifest V3
- React
- TypeScript
- Vite
- `chrome.storage.local`
- `chrome.alarms`
- `chrome.notifications`

## Project Skeleton

The first commit only prepares the directory and tool configuration for the MVP.

Implementation code will be added in later issues.

```text
src/
  background/
  popup/
    components/
  shared/
  styles/
public/
  icons/
```

## Asset Policy

Mascot frame assets are intentionally not tracked yet. Keep local files under `assets/` or `public/assets/` until the asset preparation issue is ready.
