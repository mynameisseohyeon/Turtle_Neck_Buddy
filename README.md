## 주요 기능

### 대시보드 및 리마인더

오늘의 스트레칭 진행 상황과 다음 알림까지 남은 시간을 한눈에 확인할 수 있습니다.
* 오늘 누적 스트레칭 완료 횟수 트래킹
* 다음 스트레칭 알림까지 남은 시간 실시간 표시

### 인터랙티브 가이드
짧고 직관적인 카드 형태로 스트레칭 동작을 안내합니다.
* 30초 단위의 직관적인 스트레칭 카드 UI 제공

### 사용자 맞춤형 설정

브라우저의 Local Storage를 기반으로 개인 설정과 기록을 관리합니다.
* 알림 간격 설정 (타이머 커스텀)
* 알림 On/Off 토글 기능
* 일일 기록 초기화 기능
